AI와 데이터 분석

프로그래밍 경험이 없는 이공계 학생이 데이터 분석과 AI의 핵심 개념을 이해하고, 제조·공정·실험 데이터로 간단한 분석을 직접 해 보는 온라인 강좌입니다.

  • 주 3차시 · 차시당 25분
  • Google Colab · Python
  • 생성형AI 보조 활용

교과 교육목표

  1. 데이터 분석과 인공지능의 기본 개념, 그리고 제조·연구 현장의 AI 적용 사례를 설명할 수 있다.
  2. 제공된 실습 파일과 생성형AI를 활용하여 데이터를 불러오고 정리·시각화할 수 있다.
  3. 회귀·분류·군집 등 머신러닝의 기본 원리를 이해하고, 분석 결과의 의미를 해석할 수 있다.
  4. 자신의 전공 분야 문제를 데이터 문제로 정의하고 간단한 분석 보고서로 정리할 수 있다.
